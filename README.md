# CareerCopilot AI — AI-Powered Job Application Tracker & Career Assistant

[![Next.js](https://img.shields.io/badge/Next.js-15.5-blue)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.7-blue)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-violet)](https://tailwindcss.com/)
[![Local](https://img.shields.io/badge/Data-100%25_Local-emerald)](#local-data-and-privacy)

**CareerCopilot AI** helps job seekers organize applications, analyze job descriptions using AI, score job matches deterministically, generate job-tailored ATS PDF resumes, and prepare for technical interviews.

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start Production Server
npm run build
npm start
```

Visit **`http://localhost:3000`** in your browser.

No account, login, database, or cloud sync is required.

## Local data and privacy

Jobs, applications, profile information, resumes, reminders, interviews, and LLM settings are stored in this browser's `localStorage`. Clearing site data clears the application data. An API key is sent through the local Next.js process only while testing or using its configured provider; it is never written to a server-side database.
